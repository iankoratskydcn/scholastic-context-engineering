## Novelty-threat scan: ranked overlaps

### Tier 1 — direct overlaps that must be explicitly differentiated

1. **Trajano et al. (2024), FAIA240329 — strongest threat.** Scheme classification is used to provide LLM context for converting natural-language arguments to computational arguments. The paper explicitly discusses RAG, scheme examples, short versus larger context, and the possibility that vector retrieval returns examples from the wrong scheme. This is very close to any proposal that “classifies the argument scheme, then selects scheme-relevant context for LLM reasoning.” Novelty survives only if the proposed contribution adds a demonstrably new mechanism such as learned scheme-conditioned retrieval, budget-aware compression, adaptive evidence selection, or reasoning gains measured against this baseline.
2. **Lawrence & Reed (2016) — structural mining predecessor.** Scheme structure is used to identify component proposition types and reconstruct complex argumentative structure. A proposal that routes context from inferred argument roles should cite and compare against this structural decomposition lineage.
3. **Feng & Hirst (2011) — original supervised scheme classifier.** A proposal claiming the first NLP classification of Walton schemes is not novel. Its enthymeme-reconstruction motivation also overlaps with scheme-guided reasoning.
4. **Heinrich et al. (2025) — decision-tree-guided LLM classification.** Means-end decomposition is close to hierarchical routing or staged classification. It does not, on the inspected evidence, perform retrieval/compression, but it is a direct threat to claims of novel reasoning-by-decision-tree guidance.
5. **Bezou-Vrakatseli et al. (2025) — LLM benchmark.** Any LLM scheme classifier should compare against zero-/few-shot/CoT, formal descriptions, and generated descriptions, including performance on enthymemes.

### Tier 2 — near misses with implications for the design

6. **NLAS-multi (2024) and EthiX (2024):** provide synthetic multilingual and human ethical-debate training/evaluation resources. A context-selection method needs cross-dataset testing; gains on only one generated corpus are weak evidence.
7. **Visser et al. (2021) and Lawrence et al. (2019):** annotation procedures and corpus tooling establish the form/substance distinction and label uncertainty. A system should report multilabel/ambiguity behavior rather than treating every argument as a single unambiguous class.
8. **Jo et al. (2021):** logical mechanism/relation classification is not Walton scheme detection. It is a near miss that should be used as a negative control when comparing “argument form” features to scheme labels.
9. **Green (2018):** domain-specific scheme programs support richer scientific search/summarization, but are not generic Walton classification or LLM context routing.

## Synthesis for the parent review

The established NLP task is **argument-scheme identification/classification**: map a natural-language argument to a defeasible Walton pattern, often after identifying premises/conclusion and sometimes recovering enthymemes. This should be kept distinct from (a) deductive validity/form classification, (b) support/attack/neutral relation classification, and (c) domain-specific logical mechanism labels.

The strongest novelty threat is not merely “someone classified Walton schemes”; it is **scheme-conditioned LLM context provision**. Trajano et al. (2024) already classify the input and use scheme descriptions/examples as context in an LLM + RAG translation pipeline, including an explicit wrong-scheme retrieval failure mode. Existing work still leaves a plausible gap: no retained paper evaluates a dedicated, adaptive component that uses inferred scheme/form to select, rank, compress, or budget context for a downstream reasoning task, with ablations against generic embedding retrieval, direct prompting, hierarchical decision trees, and the Trajano scheme-context baseline.

A defensible new contribution should therefore claim one or more of: (1) joint uncertainty-aware scheme detection plus context routing; (2) a learned or symbolic scheme-conditioned retriever; (3) critical-question/evidence-aware compression; (4) explicit separation and ablation of Walton scheme labels versus deductive/logical-form labels; and (5) evaluation on both human-authored (EthiX/US2016G1tvWALTON-style) and generated/multilingual (NLAS-multi) data, plus downstream reasoning quality and token cost.
