# Novelty-threat scan (early pass)

**Scope.** Targeted search for prior work that (a) classifies argument forms/schemes or extracts logical structure and (b) uses that representation for proof-relevant context selection, prompt/context compression, or LLM reasoning. This is an early scan, not the final literature review; agent results are still pending.

## Preliminary assessment

The literature clearly contains the two ingredients separately, and some work combines argument-structure extraction with argument retrieval or response selection. I have **not yet verified an exact prior system** whose central pipeline is: cross-tradition argument-form classification -> deductive skeleton extraction -> proof-relevant compact context construction for an LLM generating philosophical output. That exact gap remains **unproven pending the dedicated agent sweeps**, not established fact.

The strongest novelty threats are therefore likely to be **partial overlaps**. The first batch found two especially important additions:

- **Explanation-Refiner (Quan et al., EMNLP 2024)** is the strongest direct threat: it elicits sufficient/necessary facts, identifies relevant/redundant/unrelated explanatory sentences, constructs a formal theory from selected facts, and verifies/refines the proof with Isabelle/HOL.
- **Trajano et al. (COMMA 2024)** is the strongest Walton-specific threat: scheme classification is used to provide scheme-relevant context/examples to an LLM translating natural-language arguments into computational arguments, with RAG and wrong-scheme retrieval discussed explicitly.
- **The scholastic-method sweep is thin on exact matches.** No verified paper was found that implements the full medieval sequence *quaestio → objections → sed contra → respondeo → replies* as an AI/LLM architecture.
- **Closest conceptual bridge:** Uckelman (2013) formalizes medieval *obligationes* as rule-governed dialogue with Opponent/Respondent moves and consistency evaluation.
- **Closest recent technical comparator:** Alfano et al. (2026) extracts fuzzy argumentative knowledge bases from debate text, represents support/attack relations, applies formal semantics, and answers queries. It threatens the generic “LLM span classification + formal argument graph” claim, but not the explicit scholastic protocol.
- **Closest practical convergence:** ArgLLMs, MQArgEng, debate-judging, and argumentation-based chatbots already combine LLM extraction with formal argumentation. The surviving claim must be the typed scholastic sequence, objection coverage, distinction quality, authority handling, reply alignment, provenance, and context efficiency.

1. **Argument mining and scheme classification.** Existing work identifies argumentative components, relations, and argumentation schemes. Walton and Macagno explicitly frame automated argument extraction by scheme as a useful computational goal; later annotation work operationalizes scheme labels but reports reliability difficulty. These works threaten novelty of the classification layer, not necessarily the context-engineering pipeline.
2. **LLM-based argument mining.** A 2025 survey covers LLM prompting, chain-of-thought, retrieval augmentation, long-context reasoning, interpretability, and annotation bottlenecks in argument mining. It is a direct map of adjacent work and may contain the closest overlap; the agent sweep must inspect its bibliography and cited systems.
3. **LLMs already classify Walton argument schemes.** Bezou-Vrakatseli, Cocarascu, and Modgil (ACL Findings 2025) systematically evaluate seven LLMs on Walton-scheme classification, including zero-shot, few-shot, CoT, formal definitions, LLM-generated descriptions, and enthymemes. This is a **high novelty threat to the classification component** if the project claims first use of LLMs for argument-scheme identification. The paper does not, from the inspected sections, build a proof-relevant compact context for downstream philosophical generation; that downstream use must be made explicit and evaluated.
4. **Argument retrieval/response selection.** Argument-mining surveys describe structured argument analysis supporting retrieval-based selection of relevant responses. This threatens novelty if the project claims context selection from argument structure in general; the differentiator would need to be proof-relevance, deductive skeletons, cross-tradition forms, and LLM context construction.
5. **Logical-reasoning context organization.** *Premise Order Matters in Reasoning with Large Language Models* shows that arranging premises in ground-truth proof order can change accuracy by more than 30%, with distractors worsening performance. This is strong motivation and a methodological precedent for proof-aware context ordering, but it does not by itself appear to classify natural-language spans across argument traditions or build a reusable context representation.
6. **Declarative/structured context management.** A 2026 arXiv paper, *Structured Prompt Language*, proposes declarative context management and “logical chunking” for long inputs. It is a threat to broad claims about structured context management, but the inspected abstract does not indicate argument-form or proof-relevance classification.
